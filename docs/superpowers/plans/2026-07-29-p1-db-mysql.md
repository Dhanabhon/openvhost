# MySQL Lifecycle — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Install `mysql@8.4` via Homebrew, initialize a datadir with a generated root password, run mysqld under the supervisor with real readiness, prove a connection, reveal/reset the password, and stop cleanly — surfaced on a new Databases page + Services row.

**Architecture:** see the spec (`docs/superpowers/specs/2026-07-29-p1-db-mysql-design.md`) — READ IT FIRST for every task; its D-sections are binding. Core mysql module mirrors the existing `php/` module family; supervision extends `ServiceSpec` (readiness probe + grace) with defaults that keep nginx/php-fpm behavior byte-identical; my.cnf renders via openvhost-conf; orchestration (install/init) mirrors the PHP install task pattern in src-tauri; UI mirrors Languages.

**Tech Stack:** Rust workspace + Tauri v2/SvelteKit, sqlx (state.db, committed `.sqlx/`), Tera, vitest SSR-only for Svelte.

## Phase A — proc + core + conf (Tasks 1–4)

### Task 1: `ServiceSpec` readiness probe + per-service grace (openvhost-proc)

**Files:** `crates/openvhost-proc/src/supervisor.rs`, `service_task.rs` (+ wherever `ServiceSpec`/`GRACE_DEADLINE` actually live — read first); tests in the crate's existing test layout.

**Interfaces (contract for Tasks 5):**
```rust
pub enum ReadinessProbe {
    AliveAfter(Duration),                      // default: 500ms — today's behavior, verbatim
    Command { argv: Vec<String>, deadline: Duration }, // exit 0 = ready; re-run until deadline
}
// ServiceSpec gains: pub readiness: ReadinessProbe, pub grace: Duration (default 5s)
```
Semantics (spec D4): with `Command`, the service stays `Starting` until the probe exits 0; probe deadline elapsed or child exit → `Failed` carrying child stderr tail + probe diagnostics. Stop path: SIGTERM → wait `spec.grace` → SIGKILL (process-group logic unchanged; only the constant becomes per-spec). nginx/php-fpm spec call sites updated to the defaults ONLY (explicit `AliveAfter(500ms)`, `5s` — or a `Default` impl; match crate style).

- [ ] Tests RED first: (a) `Command` probe that succeeds on Nth attempt → state visibly `Starting` until then, `Running` after; (b) probe that never succeeds within deadline → `Failed` with diagnostics; (c) long-grace spec: child that ignores SIGTERM for 8s under `grace: 15s` is NOT killed at 5s and exits via SIGTERM path (vacuity: set grace back to 5s, watch it get SIGKILLed/fail); (d) default-spec behavior byte-compatible (existing tests untouched and green).
