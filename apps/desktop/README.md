# OpenVHost Desktop

The OpenVHost desktop app: a SvelteKit UI inside a Tauri 2 shell.

- `src/` — SvelteKit routes and UI code
- `src-tauri/` — the Rust shell (thin Tauri commands only)
- `src/lib/ipc/` — the **only** module allowed to touch Tauri IPC (master plan
  §5). `bindings.ts` is generated by tauri-specta and committed; CI fails if it
  is stale.

## Prerequisites

- Node (version in [`.nvmrc`](.nvmrc)) and [pnpm](https://pnpm.io) — pnpm is
  the only supported package manager here
- Rust, pinned by the repo-root `rust-toolchain.toml`
- [Tauri 2 system dependencies](https://tauri.app/start/prerequisites/) for
  your OS

## Develop

```sh
pnpm install    # JS dependencies
pnpm tauri dev  # run the desktop app (compiles the Rust shell)
pnpm dev        # UI-only Vite dev server (no Tauri IPC available)
```

## Gates (run before pushing)

```sh
pnpm lint   # prettier + eslint
pnpm check  # svelte-check
pnpm test   # vitest
pnpm build  # production build
```

Workspace-wide commands and the roadmap live in the repo-root `CLAUDE.md` and
`docs/OPENVHOST_MASTER_PLAN.md`.
